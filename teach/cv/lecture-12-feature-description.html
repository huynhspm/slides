1.
From Detection to Description

Detection vs. Description

Descriptor: A vector that summarizes the appearance around a feature, so two features can be compared numerically.

Detection

Where is the feature?

Description

What does it look like?

Invariance: The Key Goal

A good descriptor gives the same vector for the same physical point despite changes in:

Illumination — brightness/contrast
Scale — object size
Rotation — orientation
Viewpoint — small perspective change

Key Idea: Invariance is what makes matching across different images possible.

2.
Texture Descriptors

Local Binary Patterns (LBP)

Threshold each neighbor against the center pixel, read the bits as a binary number:

  • 8 neighbors → an 8-bit code per pixel
  • Histogram of codes describes local texture
  • Fast, and invariant to monotonic lighting changes

Gray-Level Co-occurrence Matrix (GLCM)

Counts how often pairs of gray levels occur at a given offset $(\Delta x, \Delta y)$.

From it we compute texture statistics:

  • Contrast, energy
  • Homogeneity, correlation
  • Entropy

Gabor Filters

A Gabor filter is a sinusoid modulated by a Gaussian — tuned to a frequency and orientation:

$$g(x,y) = e^{-\frac{x'^2 + \gamma^2 y'^2}{2\sigma^2}} \cos\!\Big(2\pi\frac{x'}{\lambda} + \psi\Big)$$

  • A bank of Gabor filters at many scales & orientations captures texture
  • Closely models the human visual cortex
  • Responses form a rich texture descriptor

3.
Gradient Descriptors

Histogram of Oriented Gradients (HOG)

Describe a region by the distribution of gradient orientations:

  1. Compute gradients over the patch
  2. Divide into cells; build an orientation histogram per cell
  3. Normalize over blocks for lighting invariance
  4. Concatenate into one vector

Classic for pedestrian detection.

The SIFT Descriptor

SIFT (Scale-Invariant Feature Transform) builds a robust keypoint descriptor:

  • Detect at scale-space extrema (DoG)
  • Assign a dominant orientation → rotation invariance
  • 4×4 cells × 8 orientations → 128-D vector
  • Normalized for illumination invariance
[Figure placeholder]
Description: A keypoint patch rotated to its dominant orientation, its 4×4 grid of 8-bin orientation histograms forming a 128-D vector.
Image prompt: The classic SIFT diagram — gradient patch on left, 4×4 array of orientation histograms on right.

Descriptor Families

Descriptor Captures Strength
LBP Local texture Fast, lighting-robust
Gabor Frequency & orientation Rich texture
HOG Gradient shape Object detection
SIFT Keypoint appearance Scale & rotation invariant

4.
Shape Descriptors

Contour & Region Descriptors

  • Contour-based: describe the object boundary — chain codes, Fourier descriptors, signatures
  • Region-based: describe the filled shape — area, perimeter, compactness, moments
  • Useful when shape, not texture, is what distinguishes objects

Hu Moments

Seven Hu moments are combinations of normalized central moments that are invariant to:

Translation
Scale
Rotation

Key Idea: A tiny 7-number descriptor that recognizes a shape no matter where, how big, or how rotated it is.

Summary

  • A descriptor turns a feature's local appearance into a comparable vector.
  • Invariance to lighting, scale, and rotation is the central design goal.
  • Texture: LBP, GLCM, Gabor. Gradient: HOG, SIFT.
  • Shape: contour/region descriptors and invariant Hu moments.
  • Next: using descriptors to match features across images.
