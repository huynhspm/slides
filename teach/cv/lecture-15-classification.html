1.
The Classification Problem

What is Image Classification?

Task: Assign an input image a single label from a fixed set of categories — the canonical high-level vision problem.

  • Input: an image → Output: a class (cat, dog, car…)
  • The building block for detection, segmentation, and retrieval
  • Benchmarked on datasets like ImageNet (1000 classes)

Why is it Hard?

Viewpoint

The same object from many angles

Illumination

Lighting changes pixel values

Deformation & occlusion

Shape changes, partial views

Intra-class variation

Chairs come in endless forms

Key Idea: There is no simple rule — we take a data-driven approach: learn from labeled examples.

2.
Classical Pipeline

Features + Classifier

1

Extract features — SIFT/HOG, or a bag-of-visual-words histogram

2

Train a classifier on the feature vectors

3

Predict the label of new images

Features are hand-crafted (Part 3); only the classifier is learned.

k-Nearest Neighbors

Classify by the majority label among the $k$ closest training examples in feature space.

  • No training — just store the data
  • Slow at test time; sensitive to the distance metric
  • A simple baseline

Support Vector Machines

Find the hyperplane that separates classes with the maximum margin.

  • Strong generalization from limited data
  • The kernel trick handles non-linear boundaries
  • A dominant classifier before deep learning

3.
Deep Classification

End-to-End CNN Classifiers

  • A CNN learns features and the classifier together, end-to-end
  • A final softmax layer outputs class probabilities
  • Trained by minimizing cross-entropy loss with backpropagation
  • The 2012 AlexNet result on ImageNet launched the deep learning era

Landmark Architectures

AlexNet (2012) — deep CNNs + GPUs win ImageNet
VGG (2014) — deeper, uniform 3×3 convolutions
ResNet (2015) — skip connections enable very deep nets
Vision Transformers (2020+) — attention over image patches

4.
Evaluation

Metrics

Accuracy

Fraction of images classified correctly.

Top-k accuracy

Correct if the true label is in the top $k$ predictions (common: top-5).

Precision / Recall / F1

Per-class quality, important for imbalanced data.

The Confusion Matrix

Rows = true class, columns = predicted class.

  • Diagonal = correct predictions
  • Off-diagonal = which classes get confused
  • Reveals systematic errors a single accuracy number hides

Summary

  • Classification assigns an image one label — hard due to viewpoint, lighting, and intra-class variation.
  • The classical pipeline pairs hand-crafted features with k-NN or SVM.
  • CNNs learn features and classifier end-to-end — AlexNet → ResNet → ViT.
  • Evaluate with accuracy, top-k, and the confusion matrix.
