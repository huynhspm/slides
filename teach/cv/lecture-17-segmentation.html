1.
The Segmentation Problem

What is Segmentation?

Task: Assign every pixel a class label — the finest-grained image understanding.

  • Classification labels the whole image; detection draws boxes; segmentation labels pixels
  • Output is a label map the same size as the input
  • Essential where precise boundaries matter

Three Flavors

Semantic

Label each pixel by class — all cars are the same "car" region.

Instance

Separate each object — car #1, car #2, … as distinct masks.

Panoptic

Both — "stuff" (sky, road) by class + "things" (cars) by instance.

2.
Classical Methods

Threshold & Region-Based

Thresholding

Split by intensity — e.g. Otsu's method picks the threshold automatically.

Region growing

Start from seeds and merge similar neighboring pixels.

Watershed treats intensity as a terrain and floods basins — good for touching objects.

Clustering-Based

Group pixels by feature similarity (color, position):

  • k-means on color values
  • Mean-shift finds density modes
  • Superpixels (SLIC) group into coherent patches

3.
Deep Segmentation

Fully Convolutional Networks

  • Replace the classifier's dense layers with convolutions → output a spatial map
  • Predict a class for every pixel in one pass
  • Downsampling loses resolution → need to upsample back
  • Trained with per-pixel cross-entropy loss

Encoder–Decoder & U-Net

An encoder compresses; a decoder upsamples back to full resolution.

  • Skip connections carry fine detail from encoder to decoder
  • U-Net is the classic design — dominant in medical imaging
  • Later: dilated convolutions (DeepLab), transformers

4.
Evaluation & Applications

Metrics: IoU & mIoU

Compare predicted and true masks per class:

$$\text{IoU} = \frac{|P \cap G|}{|P \cup G|}$$

  • mIoU = mean IoU averaged over all classes — the standard metric
  • Pixel accuracy is also reported but misleads on imbalanced classes
  • Dice coefficient is common in medical imaging

Applications

Autonomous driving

Road, lane, and obstacle maps.

Medical imaging

Organ & tumor delineation.

Satellite imagery

Land use & crop mapping.

Photo editing

Background removal, portrait mode.

Summary

  • Segmentation labels every pixel — semantic, instance, or panoptic.
  • Classical methods use low-level cues: thresholding, region growing, clustering, watershed.
  • Deep models (FCN, U-Net) predict dense maps with encoder-decoder + skip connections.
  • Evaluated with IoU / mIoU.
  • Next: understanding motion over time — object tracking.
