1.
Introduction

Motivation

Why?

Real-world images are often degraded by noise, blur, or compression artifacts during image acquisition, transmission, or storage.

Goal?

Recover the original image using a known or estimated degradation model.

Restoration vs. Enhancement

Image Restoration Image Enhancement
Recovers the true, original image Makes the image look better to the eye
Objective: judged by how accurate it is Subjective: judged by how it looks
Relies on a model of how the image was degraded Does not need to know how the image was degraded
Denoising, deblurring, deconvolution Contrast enhancement, histogram equalization, sharpening

Common Causes

  • Blur
  • Noise
  • Other degradations

Applications

Medical Imaging Noise reduction
Remote Sensing Deblurring and atmospheric correction
Surveillance Low-light denoising
Autonomous Driving Motion deblurring
Smartphone Photography Denoising and deblurring

2.
Image Degradation Model

2.1 Image Degradation Process

\[g(x, y) = h(x, y) * f(x, y) + \eta(x, y)\]

  • \( f(x, y) \) — the original (unknown) image
  • \( h(x, y) \) — the degradation function (e.g. blur kernel)
  • \( * \) — convolution operator
  • \( \eta(x, y) \) — additive noise
  • \( g(x, y) \) — the observed degraded image

Goal: recover \( f(x,y) \) given \( g(x,y) \), and knowledge (or estimates) of \( h \) and \( \eta \).

2.2 Noise Models

  • Gaussian noise — sensor/thermal noise, symmetric bell-shaped distribution
  • Salt-and-pepper noise — random black/white pixels from transmission errors
  • Poisson (shot) noise — signal-dependent, common in low-light imaging
  • Speckle noise — multiplicative, common in radar/ultrasound imaging
  • Periodic noise — structured interference from electrical/mechanical sources

2.3 Blur Models

  • Motion blur — relative motion between camera and scene during exposure
  • Defocus (Gaussian) blur — out-of-focus optical system
  • Atmospheric blur — turbulence in the imaging medium

Each blur type corresponds to a different point spread function \( h(x, y) \).

3.
Image Restoration Techniques

3.1 Image Denoising

  • Spatial filtering — mean, median, Gaussian, bilateral filters
  • Frequency-domain filtering — low-pass filtering in the Fourier domain
  • Wavelet denoising — thresholding wavelet coefficients
  • Learning-based denoising — CNN / diffusion models trained to predict noise

3.2 Image Deblurring

  • Inverse filtering — divide by the degradation function in the frequency domain
  • Wiener filtering — inverse filtering that accounts for noise, minimizing mean square error
  • Blind deconvolution — estimate both the image and the unknown blur kernel

\[\hat{F}(u,v) = \left[\frac{1}{H(u,v)} \frac{|H(u,v)|^2}{|H(u,v)|^2 + K}\right] G(u,v)\]

3.3 Periodic Noise Reduction

  • Periodic noise appears as isolated peaks in the Fourier spectrum
  • Notch filtering — reject narrow frequency bands around the peaks
  • Band-reject filtering — reject a range of frequencies

4.
Restoration Evaluation

4.1 Quality Metrics

  • MSE (Mean Squared Error) — average squared pixel-wise difference
  • PSNR (Peak Signal-to-Noise Ratio) — logarithmic measure derived from MSE
  • SSIM (Structural Similarity Index) — perceptual similarity in luminance, contrast, structure
  • LPIPS — learned perceptual metric using deep features

4.2 Visual Comparison

  • Quantitative metrics don't always align with perceived quality
  • Side-by-side comparison of degraded, restored, and ground-truth images
  • Zoomed-in crops to inspect fine detail and artifacts

Summary

  • Image restoration recovers an original image from a modeled degradation (blur + noise)
  • Techniques range from classical filtering (Wiener, notch filters) to learning-based approaches
  • Evaluation combines objective metrics (PSNR, SSIM) with visual inspection
