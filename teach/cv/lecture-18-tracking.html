1.
The Tracking Problem

What is Object Tracking?

Task: Follow one or more objects across the frames of a video, maintaining a consistent identity for each.

Single-object (SOT)

Track one target given its first box.

Multi-object (MOT)

Track many targets, keeping IDs distinct.

Why is Tracking Hard?

Occlusion

Targets hide behind others

Appearance change

Pose, lighting, scale shift

ID switches

Crossing objects swap identities

Real-time need

Must keep up with video

Key Idea: Tracking combines motion prediction with appearance matching.

2.
Motion & Classical Trackers

Optical Flow

Estimate per-pixel motion between frames, assuming brightness is constant:

$$I_x u + I_y v + I_t = 0$$

  • Lucas–Kanade: sparse, for keypoints
  • Farnebäck: dense flow field

Mean-Shift & Kalman Filter

Mean-Shift

Iteratively move a window toward the region whose color histogram best matches the target.

Kalman Filter

Predict the next state from a motion model, then correct with the new measurement.

Key Idea: The Kalman filter smooths trajectories and bridges short gaps (e.g. brief occlusion).

3.
Modern Tracking

Tracking-by-Detection

1

Detect objects in each frame (Lecture 16)

2

Predict each track's next position (Kalman)

3

Associate detections to tracks (Hungarian algorithm on IoU / appearance)

4

Update tracks; spawn / kill as needed

SORT & DeepSORT

SORT

Kalman + Hungarian on IoU. Simple and very fast, but IDs switch under occlusion.

DeepSORT

Adds a learned appearance embedding so identities survive occlusion.

Newer trackers use transformers and joint detection-tracking networks.

4.
Evaluation & Course Wrap-up

Tracking Metrics

  • MOTA — Multiple Object Tracking Accuracy (misses, false positives, ID switches)
  • MOTP — precision of matched box locations
  • IDF1 — how consistently identities are preserved
  • ID switches — count of identity swaps (lower is better)

Summary

  • Tracking follows objects over time, keeping consistent identities despite occlusion and change.
  • Classical tools: optical flow, mean-shift, and the Kalman filter.
  • Modern tracking-by-detection (SORT, DeepSORT) pairs detection with motion + appearance association.
  • Evaluated with MOTA, MOTP, IDF1, and ID switches.
