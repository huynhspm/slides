1.
Hand-crafted vs. Learned

The Limits of Hand-crafted Features

  • SIFT, HOG, LBP are designed by hand — clever, but fixed
  • Each is tuned for specific cues; none adapts to a new task
  • Designing them requires deep expertise and trial-and-error
  • They struggle with complex, high-level semantics

Key Question: Can we learn the best features directly from data instead of designing them?

Representation Learning

Idea: Let a model learn a mapping from raw pixels to useful feature vectors, optimized end-to-end for the task.

Hand-crafted

Human designs the feature extractor; fixed across tasks.

Learned

Data + optimization discover the features; adapts to the task.

2.
CNNs as Feature Learners

Convolutional Neural Networks

  • Learn convolution kernels instead of hand-setting them
  • Stacked layers of convolution, nonlinearity, and pooling
  • Weight sharing & locality → far fewer parameters than dense layers
  • Trained by backpropagation to minimize a task loss

A Hierarchy of Features

Early layers

Learn edges and color blobs — much like Gabor filters, but discovered automatically.

Middle layers

Combine edges into textures, motifs, and object parts.

Deep layers

Represent whole objects and semantic concepts.

Key Idea: Depth builds abstraction — the same low→mid→high progression as classical vision, but learned.

3.
Embeddings

Features as Embeddings

A network maps each image to a point in a high-dimensional embedding space.

  • Similar images → nearby points
  • Distance = semantic similarity
  • Enables search, clustering, and retrieval

Metric Learning

Train the embedding so distances mean what we want, e.g. the triplet loss:

$$\|f(a) - f(p)\|^2 + \alpha < \|f(a) - f(n)\|^2$$

  • Pull the anchor $a$ and positive $p$ together
  • Push the negative $n$ away by a margin $\alpha$
  • Powers face recognition and image retrieval

4.
Transfer & Self-Supervision

Transfer Learning

  • Pretrain a network on a large dataset (e.g. ImageNet)
  • Reuse its learned features on a new task with little data
  • Feature extraction: freeze the backbone, train a new head
  • Fine-tuning: continue training some layers on the new task

Key Idea: Learned features transfer — general visual knowledge is reused across tasks.

Self-Supervised & Foundation Models

  • Self-supervision learns from unlabeled images via pretext tasks (contrastive learning, masked image modeling)
  • Vision Transformers (ViT) apply attention to image patches
  • Vision-language models (e.g. CLIP) align images and text in one embedding space
  • Large foundation models provide reusable general-purpose representations

Summary

  • Representation learning learns features from data instead of hand-designing them.
  • CNNs build a hierarchy — edges → parts → objects — echoing classical low/mid/high levels.
  • Embeddings place images in a space where distance means similarity; metric learning shapes it.
  • Transfer and self-supervised learning reuse representations across tasks.
  • These learned features drive the high-level tasks in Part 4.
