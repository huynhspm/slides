Bounding Boxes & IoU

A box is $(x, y, w, h)$. We measure box overlap with Intersection over Union:

$$\text{IoU} = \frac{\text{area of overlap}}{\text{area of union}}$$

A prediction is "correct" if IoU with the ground truth exceeds a threshold (e.g. 0.5).

2.
Sliding Window & Proposals

Sliding Window

  • Slide a classifier over every position and scale
  • Simple, but enormously expensive — millions of windows
  • Classic use: HOG + SVM for face and pedestrian detection

Key Idea: We need to test far fewer windows — only the promising ones.

Region Proposals: R-CNN Family

R-CNN — propose ~2000 regions, run a CNN on each (slow)
Fast R-CNN — share one CNN pass, crop features (RoI pooling)
Faster R-CNN — a learned Region Proposal Network — end-to-end

These are two-stage detectors: propose, then classify.

3.
Modern Detectors

One-Stage Detectors

YOLO and SSD predict boxes and classes in a single network pass.

  • Divide the image into a grid; each cell predicts boxes
  • Much faster — enables real-time detection
  • Slightly lower accuracy than two-stage (gap now small)

Anchors & Two-Stage vs One-Stage

Two-stage (Faster R-CNN) One-stage (YOLO / SSD)
Propose then classify Predict directly
Higher accuracy Higher speed (real-time)
Uses anchor boxes of preset shapes Anchor-based or anchor-free

4.
Evaluation

Non-Maximum Suppression

Detectors output many overlapping boxes for one object. NMS keeps only the best:

  1. Sort boxes by confidence
  2. Keep the top box
  3. Remove others with high IoU to it
  4. Repeat
[Figure placeholder]
Description: Many overlapping boxes on one object before NMS, a single clean box after.
Image prompt: Before/after — a cluster of boxes reduced to one tight box by NMS.

Mean Average Precision (mAP)

  • For each class, sweep the confidence threshold to trace a precision-recall curve
  • Average Precision (AP) = area under that curve
  • mAP = mean of AP over all classes (often at IoU = 0.5, or averaged over IoUs)
  • The standard detection benchmark metric (COCO, Pascal VOC)

Summary

  • Detection = classification + localization for all objects, scored by IoU.
  • Sliding windows gave way to region proposals (R-CNN → Faster R-CNN).
  • One-stage detectors (YOLO, SSD) trade a little accuracy for real-time speed.
  • NMS cleans up boxes; mAP measures overall quality.
  • Next: labeling every pixel — semantic segmentation.
