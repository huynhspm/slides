1.
Foundations

What is Morphology?

Morphology: A set of operations that process images based on shape, using set theory on the pixels.

  • A binary image is treated as a set of foreground pixel coordinates in 2D integer space
  • Extracts structures: boundaries, skeletons, convex hulls
  • Enables filtering, thinning, thickening, and pruning of shapes

The Structuring Element

A small structuring element (SE) probes the image. Its shape and origin define how the operation behaves.

  • Can be a square, cross, disk, line…
  • Represented as a set, a graphic, or a small array
  • The origin (dot) marks the anchor pixel

Reflection & Translation

Reflection $\hat{B}$

Rotate the SE $180°$ about its origin.

$$\hat{B} = \{-b \mid b \in B\}$$

Translation $(B)_z$

Slide the SE to position $z$.

$$(B)_z = \{b + z \mid b \in B\}$$

Key Idea: Every morphological operation slides the SE over the image and applies a set operation at each position.

2.
Erosion & Dilation

Erosion

$$A \ominus B = \{z \mid (B)_z \subseteq A\}$$

Keep positions where the SE fits entirely inside the object.

  • Shrinks / thins objects
  • Removes small details & thin protrusions
[Figure placeholder]
Description: A binary shape before and after erosion, shrunk inward by the SE radius.
Image prompt: A white blob on black, then eroded to a smaller blob, with the SE shown.

Dilation

$$A \oplus B = \{z \mid (\hat{B})_z \cap A \neq \varnothing\}$$

Keep positions where the reflected SE touches the object.

  • Grows / thickens objects
  • Fills small holes & gaps

Description: A binary shape before and after dilation, expanded outward by the SE.
Image prompt: A white blob on black, then dilated to a larger blob with small holes filled.

Duality of Erosion & Dilation

Erosion and dilation are duals with respect to complement and reflection:

$$(A \ominus B)^c = A^c \oplus \hat{B}$$

Key Idea: Eroding the foreground is the same as dilating the background — one operation implies the other.

3.
Opening & Closing

Opening

$$A \circ B = (A \ominus B) \oplus B$$

Erosion then dilation.

  • Removes small objects & thin protrusions
  • Smooths contours from the outside
  • Preserves overall object size
[Figure placeholder]
Description: A noisy shape with thin spikes cleaned up by opening.
Image prompt: A blob with thin spikes/specks, then opened to remove them while keeping the main body.

Closing

$$A \bullet B = (A \oplus B) \ominus B$$

Dilation then erosion.

  • Fills small holes & gaps
  • Smooths contours from the inside
  • Connects nearby objects
[Figure placeholder]
Description: A shape with small holes and gaps filled in by closing.
Image prompt: A blob with pinholes and a narrow gap, then closed to fill them.

Properties

Opening Closing
Removes bright specks on dark background Fills dark holes on bright objects
Idempotent: $(A \circ B) \circ B = A \circ B$ Idempotent: $(A \bullet B) \bullet B = A \bullet B$

4.
Applications

Boundary Extraction

Subtract an eroded copy from the original to get the outline:

$$\beta(A) = A - (A \ominus B)$$

The morphological gradient $(A \oplus B) - (A \ominus B)$ highlights edges similarly.

Hit-or-Miss & Skeletons

Hit-or-Miss Transform

Detects exact shape patterns using a pair of SEs (foreground + background) — the basis of template matching in binary images.

Skeletonization

Thins a shape to a 1-pixel-wide medial axis — a compact representation for recognition.

Thinning, Thickening, Pruning

Iterative refinements built from hit-or-miss — clean up skeletons and remove spurs.

Real-World Uses

Barcode detection

Closing joins bars into a solid region.

Document cleanup

Opening removes speckle noise from scans.

Medical imaging

Isolate and measure cells or vessels.

Fingerprints

Thinning ridges before matching.

Summary

  • Morphology processes shape using set operations with a structuring element.
  • Erosion shrinks, dilation grows — and they are duals.
  • Opening removes specks; closing fills holes — both are idempotent.
  • Derived tools: boundary extraction, gradient, hit-or-miss, skeletons.
  • Widely used for cleanup, detection, and shape analysis in binary images.
