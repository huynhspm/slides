1.
Image Operations

Motivation

Question: How can we improve this image? $\rightarrow$ Image Enhancement

Image Enhancement

✖
Does not create new information

Enhancement cannot recover information that is completely lost from the original image.

✔
Only highlights existing information

Transforms the image to make it easier to observe or process, for humans or algorithms.

Key Idea: Image Enhancement is a transformation that highlights desired features of an image.

Image Transformation

$$g(x,y) = T\big(f(x,y)\big) \quad \text{or} \quad g = T(f)$$

$f$

Input image

$T$

Transformation

$g$

Output image

Key Idea: This is the foundational model used to explain the different types of image operations.

Types of Image Operations

P
Point Operations

Output pixel depends only on the corresponding input pixel.
$g(x,y) = T(f(x,y))$

L
Local Operations

Output pixel depends on a neighborhood of input pixels.
$g(x,y) = T(f(\text{neighborhood of } x,y))$

G
Global Operations

Output pixel depends on all pixels in the image.
$g(x,y) = T(f)$

Key Idea: These operations differ in the amount of information used to compute a single output pixel.

2.
Intensity Transformations

Formulation

Intensity Transformation

A transformation that remaps the intensity value of each pixel.

Point Operations

Each output pixel depends only on the corresponding input pixel.

General Transformation Function

$$s = T(r)$$

$r$

Input intensity

$s$

Output intensity

$T(\cdot)$

Transformation function

Image Negative

$$s = (L - 1) - r$$

$L$ is the number of intensity levels (e.g. $L=256$ for 8-bit images).

Goal

Enhance white or gray detail embedded in dark regions of an image.

What?

Reverses intensity levels: dark becomes light and light becomes dark.

Key Idea: Invert intensity values so that dark and light regions swap.

Image Negative

Applications
  • Enhancing white or gray detail embedded in dark regions of an image (e.g. medical images).
  • Producing film-like negatives for artistic or analog photography effects.
  • Highlighting features in mammograms and other diagnostic scans.

Gamma Transformation

$$s = c \, r^{\gamma}$$

Gamma transformation operates on normalized intensities in $[0,1]$.

1. Normalize

$r \in [0, L-1] \rightarrow r_n = \dfrac{r}{L-1} \in [0,1]$

2. Apply Power

$s_n = c \, r_n^{\gamma}$

3. Re-normalize

$s = s_n \times (L-1)$

$\gamma < 1$

Expands dark regions, compresses bright regions

$\gamma > 1$

Expands bright regions, compresses dark regions

Key Idea: Nonlinearly remap all intensities using a power function.

Gamma Transformation

Applications
  • Gamma correction for displays, cameras, and printers to match human perception of brightness.
  • Enhancing contrast in medical or satellite images with a narrow dynamic range.
  • Preprocessing step before feeding images into computer vision models.
Further reading: Log Transformation.

Contrast Stretching

1
Contrast

The difference in intensity between the brightest and darkest parts of an image. Low contrast means intensities are crowded into a narrow range.

2
Goal

Choose $(r_1, r_2)$ as the range to expand, and $(s_1, s_2)$ as the target range:

Expand middle

$r_1 \to r_2$ maps to $s_1 \to s_2$ (wider range)

Compress others

$0 \to r_1$ maps to $0 \to s_1$

$r_2 \to 255$ maps to $s_2 \to 255$

$(0,0)$ $(r_1, s_1)$ $(r_2, s_2)$ $(255,255)$

4 control points define the transformation.

Key Idea: Redistribute intensities to increase contrast in a selected range.

Contrast Stretching

Line Through Two Points

$$y = y_1 + \dfrac{y_2 - y_1}{x_2 - x_1}(x - x_1)$$

General Transformation Function

Control points: $(0,0)$, $(r_1, s_1)$, $(r_2, s_2)$, $(255, 255)$

$$s = \begin{cases} \dfrac{s_1}{r_1}\,r & 0 \leq r < r_1 \\[12pt] s_1 + \dfrac{s_2 - s_1}{r_2 - r_1}(r - r_1) & r_1 \leq r < r_2 \\[12pt] s_2 + \dfrac{255 - s_2}{255 - r_2}(r - r_2) & r_2 \leq r \leq 255 \end{cases}$$

Intensity-level Slicing

Goal

Highlight a specific range of intensity values $[A, B]$ (e.g. to isolate a feature) by mapping it to a high value $H$ (typically $H=255$), while deciding what happens to the rest of the image.

With Background

Keep values outside $[A,B]$ unchanged.

$$s = \begin{cases} H & A \leq r \leq B \\[6pt] r & \text{otherwise} \end{cases}$$

Without Background

Set values outside $[A,B]$ to $0$.

$$s = \begin{cases} H & A \leq r \leq B \\[6pt] 0 & \text{otherwise} \end{cases}$$

Key Idea: Highlight a selected intensity range.

Intensity-level Slicing

Applications
  • Highlighting specific structures in medical images (e.g. bones in an X-ray).
  • Enhancing features in satellite or aerial imagery (e.g. water bodies, terrain types).
  • Isolating flaws or defects in industrial inspection images.

Thresholding

$$s = \begin{cases} 0 & \text{if } r < T \\[6pt] L-1 & \text{if } r \geq T \end{cases}$$

Key Idea: Separate pixels into classes.

Connection: Thresholding is an extreme case of contrast stretching when:

$r_1=r_2=T$, $s_1=0$, $s_2=L-1$.

3.
Histogram Processing

Histogram

Definition

Histogram = frequency distribution of intensity values.

$$h(r_k) = n_k$$

$r_k$: the $k$-th intensity level.
$n_k$: the number of pixels with that intensity.

Key Idea: A histogram describes the intensity distribution of an image.

Interpret a Histogram

Narrow, shifted left

Low contrast, dark image.

Narrow, shifted right

Low contrast, bright image.

Wide, spread out

High contrast, good tonal range.

Multiple peaks

Distinct regions or objects.

Histogram Equalization

Goal

Redistribute intensities to flatten the histogram and improve global contrast.

Transformation Function

$$s_k = (L-1) \sum_{j=0}^{k} p(r_j)$$

The cumulative distribution function (CDF) of the intensities, scaled to $[0, L-1]$.

Key Idea: Spreads out the most frequent intensities, boosting global contrast automatically — no manual thresholds needed.

Histogram Matching

Goal

Transform an image's histogram to match a specified target histogram, instead of a flat one.

1. Equalize

Map source image to a flat histogram via $s_k = (L-1)\sum p(r_j)$.

2. Equalize target

Map desired histogram to the same flat histogram.

3. Invert

Chain the source mapping with the inverse of the target mapping.

Key Idea: Also called histogram specification — useful for matching the tone of a reference image.

Local Histogram Equalization

Problem

Global equalization uses one histogram for the whole image — local details in small regions can still be lost.

Solution

Slide a small window over the image and equalize using only the histogram of that neighborhood.

Key Idea: A local operation — the output pixel now depends on its neighborhood, not just its own value.

CLAHE

Contrast Limited Adaptive Histogram Equalization

Local histogram equalization applied on small tiles, with a clip limit to prevent over-amplifying noise.

Clip Limit

Cap the histogram bins before computing the CDF, redistributing the clipped excess evenly.

Tile Boundaries

Interpolate between neighboring tiles to avoid visible block artifacts.

Key Idea: Balances local contrast enhancement with noise suppression — widely used in medical imaging.

4.
Spatial Filtering

Convolution

$$g(x,y) = \sum_{s=-a}^{a} \sum_{t=-b}^{b} h(s,t)\, f(x-s, y-t)$$

What?

Slide a kernel $h$ over the image and compute a weighted sum at each position.

Why?

Foundation for all local spatial filtering operations.

Spatial Filtering

1
Smoothing

Reduce noise and detail using low-pass filters (mean, Gaussian, median).

2
Sharpening

Enhance fine detail and edges using high-pass filters (Laplacian, unsharp masking).

3
Edge Detection

Locate intensity discontinuities using gradient-based operators (Sobel, Prewitt).

Smoothing

Goal

Blur out noise and small variations.

Trade-off

Larger kernels smooth more but blur edges.

  • Mean filter: average of neighborhood
  • Gaussian filter: weighted average, less blurring of edges
  • Median filter: nonlinear, robust to salt-and-pepper noise

Sharpening

$$g(x,y) = f(x,y) + c \big[\nabla^2 f(x,y)\big]$$

  • Laplacian: second-order derivative, highlights fine detail
  • Unsharp masking: subtract a blurred version to emphasize high frequencies

Edge Detection

$$|\nabla f| = \sqrt{\left(\frac{\partial f}{\partial x}\right)^2 + \left(\frac{\partial f}{\partial y}\right)^2}$$

First-order

Sobel, Prewitt — gradient magnitude and direction.

Second-order

Laplacian — zero-crossings mark edges.
