1.
The Evaluation Problem

Why Evaluation Is Hard

There is no ground-truth output to compare against. A generated image is not wrong — it is only more or less plausible.
  • Supervised learning has labels; generation does not
  • We must compare distributions, not individual outputs

What We Actually Want

  • Fidelity — do samples look real?
  • Diversity — do they cover the data distribution?
  • Alignment — do they match the condition?
  • No single number captures all three

A Warning

Beautiful images ≠ a good generative model.
  • A model that memorises the training set scores perfectly on fidelity
  • A mode-collapsed GAN can produce stunning individual samples
  • Evaluation must catch both failures

2.
Likelihood-Based Evaluation

Log-Likelihood

$$ \log p_\theta(x) $$
  • Direct and principled — where it is available
  • Exact for autoregressive models and flows
  • Only a bound for VAEs, unavailable for GANs

Bits Per Dimension

$$ \text{BPD} = \frac{-\log_2 p_\theta(x)}{D} $$
  • Normalises by dimension so resolutions can be compared
  • Interpretable as a compression rate
  • Lower is better

Why Likelihood Is Not Enough

  • High likelihood does not imply good samples, or the reverse
  • A model can spend likelihood on imperceptible detail
  • Most probability mass sits in a region we never perceive
  • So we need sample-based metrics too

3.
Sample-Based Metrics

Inception Score

$$ \text{IS} = \exp\Big(\mathbb{E}_x \big[ D_{\mathrm{KL}}(p(y \mid x) \,\|\, p(y)) \big]\Big) $$
  • Rewards confident per-image class predictions and varied classes overall
  • Flaws: ignores the real data entirely, limited to ImageNet classes

Fréchet Inception Distance

$$ \text{FID} = \|\mu_r - \mu_g\|^2 + \operatorname{Tr}\big(\Sigma_r + \Sigma_g - 2(\Sigma_r\Sigma_g)^{1/2}\big) $$
  • Fit a Gaussian to Inception features of real and generated sets
  • Measure the distance between those two Gaussians
  • Lower is better; it does compare against real data

FID's Limitations

  • Depends entirely on the Inception feature extractor
  • Assumes Gaussian features — they are not
  • Strongly biased by sample count
  • One number cannot separate fidelity from diversity

Precision and Recall

  • Precision — fraction of generated samples inside the real manifold (fidelity)
  • Recall — fraction of real data covered by the model (diversity)
  • Separates the two failure modes that FID conflates

4.
Alignment Metrics

Text-Image Alignment

  • Fidelity metrics say nothing about whether the prompt was followed
  • A photorealistic dog for the prompt "a red cube" scores well on FID
  • Conditional generation needs an alignment metric

CLIP Score

$$ \text{CLIPScore} = \max\big(0, \quad \cos(E_I(x), E_T(c))\big) $$
  • Cosine similarity between image and text embeddings
  • Correlates reasonably with human judgements of relevance
  • Blind spots: counting, spatial relations, attribute binding

The Guidance Trap

  • Raising guidance improves CLIP score and worsens FID
  • Neither number alone tells you the model got better
  • Always report both, as a trade-off curve

5.
Human Evaluation & Protocols

Human Evaluation

  • Realism: is this image real or generated?
  • Preference: which of two images is better?
  • Alignment: which better matches the prompt?
  • Pairwise comparison is more reliable than absolute scoring

Doing It Properly

  • Fixed prompts, fixed seeds, randomised presentation order
  • Several annotators per item; report inter-annotator agreement
  • Report confidence intervals, not just means

Automatic and Human Metrics Disagree

  • Automatic metrics are cheap, reproducible and gameable
  • Human evaluation is expensive, noisy and the actual target
  • When they conflict, the humans are right

Designing an Evaluation Protocol

  • Choose metrics matching your three goals: fidelity, diversity, alignment
  • Fix sample count, resolution and feature extractor — then say so
  • Report the guidance-scale trade-off curve, not one point
  • Check for training-set memorisation

Summary

  • Generative evaluation compares distributions, not single outputs
  • Likelihood is principled but unavailable for some families and misaligned with perception
  • FID is standard but depends on its feature extractor and sample size
  • Precision/recall separates fidelity from diversity
  • CLIP score measures alignment; human evaluation remains the ground truth
