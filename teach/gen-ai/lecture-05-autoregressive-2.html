1.
From RNNs to Transformers

The Problem with Recurrence

  • RNNs compress all history into one fixed-size state
  • Long-range dependencies fade through repeated updates
  • Sequential computation prevents parallel training

Self-Attention

$$ \text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V $$
  • Every position looks at every other position directly
  • Path length between any two positions is \( O(1) \)
  • The \( \sqrt{d_k} \) keeps the softmax out of its saturated regime

Causal Masking

Set attention scores to \( -\infty \) for all future positions before the softmax.
  • Position \( i \) may attend only to positions \( \le i \)
  • This is what preserves \( p(x_i \mid x_{<i}) \)
  • The Transformer equivalent of a masked convolution

The Transformer Decoder Block

  • Masked multi-head self-attention
  • Position-wise feed-forward network
  • Residual connections and layer normalisation
  • Stack \( N \) of these blocks

Positional Information

  • Attention alone is permutation-equivariant
  • Order must be injected explicitly via positional encodings
  • For images, the encoding carries 2D spatial position

2.
Visual Tokens

Why Not Pixels?

  • Attention costs \( O(L^2) \) in sequence length
  • A \( 256\times256 \) image is \( L = 65{,}536 \) — about \( 4 \times 10^9 \) attention scores
  • We need a much shorter sequence

Visual Tokens

Compress the image into a small grid of discrete tokens, then model those tokens autoregressively.
  • \( 256\times256 \) pixels → e.g. a \( 32\times32 \) grid = 1024 tokens
  • A 64x reduction in sequence length
  • Each token is an index into a learned vocabulary

The Tokenizer — For Now, a Black Box

Assume we have an encoder mapping an image to a grid of discrete indices, and a decoder mapping them back.
  • We use it here; we build it in Lecture 07 (VQ-VAE)
  • This deferral is deliberate — the mechanism needs vector quantization
  • For today, only its interface matters

Continuous vs Discrete

  • Continuous latents — smooth, but need a density model
  • Discrete tokens — a plain softmax classifier suffices
  • Discreteness is what lets us reuse the language-model machinery

The Two-Stage Recipe

  • Stage 1: train the tokenizer (image ↔ tokens)
  • Stage 2: train a Transformer over token sequences
  • VQGAN adds a perceptual and adversarial loss to sharpen stage 1

3.
The Autoregressive Objective

The Objective Is Unchanged

$$ \mathcal{L}(\theta) = -\sum_{i=1}^{L} \log p_\theta(t_i \mid t_{<i}) $$
  • Cross-entropy over the token vocabulary
  • Identical in form to a language model — only the vocabulary differs
  • This is the bridge from image generation to GPT-style models

Relation to Language Models

  • Same architecture, same loss, same training recipe
  • Only the tokenizer changes: text sub-words vs visual tokens
  • This shared formulation is why one recipe scales across modalities

Conditioning

  • Prepend a condition to the sequence: class token, text embedding
  • The model then learns \( p(t \mid c) \) with no change to the objective
  • Simple, and it is how early text-to-image Transformers worked

4.
Sampling Strategies

Sampling Strategies

  • Greedy — always take the argmax; repetitive and dull
  • Pure sampling — sample the full distribution; can be incoherent
  • The useful methods sit between these extremes

Temperature

$$ p_\tau(t) \propto \exp\!\left(\frac{\log p(t)}{\tau}\right) $$
  • \( \tau < 1 \) sharpens toward the mode — safer, less diverse
  • \( \tau > 1 \) flattens — more diverse, more errors
  • \( \tau \to 0 \) recovers greedy decoding

Top-k and Top-p

  • Top-k: keep the \( k \) most likely tokens, renormalise
  • Top-p (nucleus): keep the smallest set with mass \( \ge p \)
  • Top-p adapts its cut-off to how peaked the distribution is

Quality vs Diversity, Again

  • Every one of these knobs trades quality against diversity
  • None of them changes the trained model — only how we read it
  • The same trade-off returns as guidance strength in Lecture 13

Summary

  • Self-attention with causal masking gives parallel training and exact likelihood
  • Pixels are too long a sequence, so we model visual tokens instead
  • The tokenizer stays a black box until Lecture 07
  • The objective is plain cross-entropy — the same as a language model
  • Sampling strategies trade quality against diversity at generation time
