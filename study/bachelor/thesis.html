1.
Introduction

Medical Image Segmentation

Common medical imaging modalities:

  • X-ray images
  • CT scans
  • Endoscopy images
  • Ultrasound images
  • MRI images

Semantic vs Instance Segmentation

Semantic Segmentation

Groups pixels of the same class together (e.g. all lesions as one region)

Instance Segmentation

Distinguishes each individual object instance separately

2.
Problem

Current Approach

An AI model is trained on (image, label) pairs to predict a single segmentation mask.

In practice, a doctor still reviews and adjusts the AI's output — a single prediction can still contain mistakes.

  • Medical data is hard and expensive to label
  • A single result reflects only one person's judgment
  • Result quality may still be imperfect, with mistakes

Hypothesis

What if, instead of one prediction, the model could simulate a group of doctors segmenting the same image independently?

Input image
→
AI model
→
Set of generated masks
→
Aggregated result + confidence map

Contributions

  • Propose using a conditional diffusion model to solve medical image segmentation, simulating a group of doctors and producing a confidence map
  • Combine an autoencoder with the conditional diffusion model to run diffusion in a latent space
  • Propose a weighted cross-entropy loss instead of MSE for the autoencoder when the segmentation mask is small
  • Implement and open-source the full model, to let the community help improve it further

3.
Method

Diffusion Model

Forward diffusion: gradually corrupts \(x_0\) into pure noise \(x_T\) via \(q(x_t | x_{t-1})\).

Reverse diffusion: a trainable network learns \(p_\theta(x_{t-1} | x_t)\) to denoise \(x_T\) back to \(x_0\).

\(x_0\)
forward →
...
→
\(x_t \rightleftarrows x_{t-1}\)
← reverse
...
←
\(x_T\)

Autoencoder Model

Input \(x\)
→
Encoder \(g[x, \theta]\)
→
\(q(z|x, \theta)\)
sample →
\(z^*\)
→
Decoder \(f[z^*, \phi]\)
→
\(Pr(x|z^*, \phi)\)

\[z^* = \mu + \Sigma^{1/2}\epsilon^*\]

Interpolation in latent space: \(z = \alpha z_1 + (1-\alpha) z_2\) produces smooth transitions between two samples.

Proposed Model: Forward Process

The segmentation mask \(x_0\) is first compressed by the encoder into a latent \(z_0\), then diffused forward into noise \(z_t, ..., z_T\) in the latent space.

\(x_0\)
→
Encoder
→
\(z_0\)
→
\(z_t\)
→
...
→
\(z_T\) (noise)

Proposed Model: Reverse Process

Starting from \(n\) independent noise samples \(z_T^1, ..., z_T^n\), conditioned on the input image (via a convolutional block), the reverse diffusion process denoises each one into a distinct latent \(z_0^i\).

\(z_T^1, ..., z_T^n\) (noise)
reverse diffusion →
\(z_0^1, ..., z_0^n\)
Decoder →
\(x^1, ..., x^n\) (masks)

Each \(z_0^i\) is decoded into its own segmentation mask \(x^i\) — simulating n different doctors.

Aggregating all \(x^i\) gives the final result and a confidence map (pixel-wise disagreement across samples).

4.
Experiment

Datasets

  • ISIC-2018 — skin lesion images
  • CVC-Clinic — endoscopy polyp images
  • BraTS-2020 — brain MRI tumor images
  • LIDC-IDRI — lung CT nodule images

Autoencoder Reconstruction Quality

Data Input Dice(%) IoU(%) SSIM PSNR
ISIC-2018 Mask 98.4 96.9 0.98 38.4
CVC-Clinic Mask 99.5 99.0 0.98 38.7
BraTS-2020 Mask 99.0 98.1 0.99 48.4
LIDC-IDRI Mask 94.4 89.4 0.99 46.7

The autoencoder reconstructs segmentation masks with high fidelity across all four datasets.

Effect of Sampling Count

Dice and IoU improve as the number of samples (simulated doctors) increases, then plateau after roughly 5–10 samples.

More samples → more stable aggregated result + sharper confidence map around ambiguous boundaries.

Effect of the Latent Space

Data Size Latent size Dice(%) IoU(%)
ISIC-2018 (64, 64) — 87.2 77.4
ISIC-2018 (256, 256) (64, 64) 88.0 80.5
BraTS-2020 (64, 64) — 87.0 76.9
BraTS-2020 (256, 256) (64, 64) 88.9 78.0

Running diffusion in a compressed latent space improves accuracy over running it directly at (64, 64) resolution.

Comparison with Other Models

Model ISIC-2018 CVC-Clinic BraTS-2020
UNet 85.6 78.5 82.3 75.0 77.3 70.6

The proposed MedSegLatDiff performs competitively with strong 1-to-1 baselines like nnUNet, while also producing a confidence map that they cannot.

5.
Conclusion

Contributions Achieved

  • Used a conditional diffusion model to solve medical image segmentation, simulating a group of doctors and producing a confidence map
  • Leveraged an autoencoder to move the process into a latent space
  • Diffusion in latent space speeds up both training and inference

Future Directions

  • Improve encoding methods and better incorporate conditioning into the model's learning process
  • Apply fast sampling methods to speed up the diffusion sampling process
  • Use a full loss function that learns both mean and variance of the data distribution, instead of the simplified loss used in this work

Summary

  • A conditional diffusion model in latent space can simulate multiple annotators for medical image segmentation
  • Results are competitive with strong 1-to-1 baselines, with the added benefit of a confidence map
  • Full source code is open-sourced for the community to build on
