Generative Modeling

Given training data, generate new samples from the same distribution.

Objectives:

  1. Learn \(p_{model}(x)\) that approximates \(p_{data}(x)\)
  2. Sampling new \(x\) from \(p_{model}(x)\)

Autoencoders

Unsupervised approach for learning a lower-dimensional feature representation from unlabeled data.

Input x
→
Encoder
→
Features z
→
Decoder
→
Reconstructed \(\hat{x}\)

Trained with L2 loss: \[\|x - \hat{x}\|^2\] — features capture meaningful factors of variation, without using labels.

We can reconstruct data, but we can't generate new images — we don't know the space of z.

VAE — Variational Autoencoder

Instead of a fixed latent vector, the encoder outputs a distribution over z: mean \(\mu\) and variance \(\sigma\), so we can sample and decode new data.

\[z = \mu + \sigma \odot \epsilon, \qquad \epsilon \sim \mathcal{N}(0, I)\]

\[\mathcal{L}(\phi, \theta, x) = \underbrace{\|x - \hat{x}\|^2}_{\text{reconstruction}} + \underbrace{D_{KL}\big(q_\phi(z|x) \,\|\, p(z)\big)}_{\text{regularization}}\]

Limitations: blurry samples, unrealistic output.

GAN — Generative Adversarial Network

Random noise z
→
Generator
→
Fake / Real images
→
Discriminator
→
Real or Fake?

Generator: tries to fool the discriminator by generating real-looking images.

Discriminator: tries to distinguish between real and fake images.

After training, use only the generator network to produce new images.

  • Unstable training
  • Mode collapse
  • Diminished gradient

Diffusion Model

Denoising Diffusion Probabilistic Models

Two processes:

  • Forward diffusion: gradually adds noise to the input
  • Reverse denoising: learns to generate data by denoising step by step
Data \(x_0\)
→
\(x_1\)
→
...
→
Noise \(x_T\)

Forward Diffusion Process

Formal definition, in T steps:

\[q(x_t | x_{t-1}) = \mathcal{N}\big(x_t; \sqrt{1 - \beta_t}\, x_{t-1}, \beta_t I\big)\]

With \(\beta_t \in (0, 1)\) and \(T\) large enough (1000 → 4000): \(x_t\) converges to \(\mathcal{N}(0, I)\) — pure noise.

Nice property — we can sample \(x_t\) directly from \(x_0\):

\[q(x_t | x_0) = \mathcal{N}\big(x_t; \sqrt{\bar\alpha_t}\, x_0, (1 - \bar\alpha_t) I\big)\]

Reverse Denoising Process

Generation starts from pure noise and iteratively denoises:

\[x_T \sim \mathcal{N}(0, I)\]

\[x_{t-1} \sim q(x_{t-1} | x_t) \quad \text{(true denoising distribution)}\]

A trainable network (U-Net, denoising autoencoder) approximates this denoising step at every \(t\).

Training and Sampling

Algorithm 1: Training
  1. \(x_0 \sim q(x_0)\)
  2. \(t \sim \text{Uniform}(\{1, ..., T\})\)
  3. \(\epsilon \sim \mathcal{N}(0, I)\)
  4. Gradient descent step on the noise-prediction loss: \[\nabla_\theta \big\| \epsilon - \epsilon_\theta(\sqrt{\bar\alpha_t} x_0 + \sqrt{1-\bar\alpha_t}\epsilon,\ t) \big\|^2\]
Algorithm 2: Sampling
  1. \(x_T \sim \mathcal{N}(0, I)\)
  2. for \(t = T, ..., 1\): \[x_{t-1} = \frac{1}{\sqrt{\alpha_t}}\Big(x_t - \frac{1-\alpha_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta(x_t, t)\Big) + \sigma_t z\]
  3. return \(x_0\)

Conditioning: Self vs Cross Attention

  • Self attention: tokens attend to each other within the same input
  • Cross attention: tokens attend to a different condition input (e.g. text, semantic map)

\[\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V\]

Latent Diffusion Model

Pixel space \(x\)
Encoder →
Latent \(z\)
Diffusion →
\(z_T\)
Decoder →
Pixel space \(\tilde{x}\)

Combines an autoencoder (pixel space ↔ latent space) with a diffusion process running in the compressed latent space, conditioned via cross-attention on text, semantic maps, images, or representations.

Running diffusion in latent space instead of pixel space is significantly cheaper and faster.

Summary

  • Diffusion models generate data via a fixed forward noising process and a learned reverse denoising process
  • Compared to VAE/GAN, diffusion models avoid blurry samples and unstable training, at the cost of slower sampling
  • Latent diffusion moves the process into a compressed latent space for efficiency, enabling conditional generation (text, images, masks)
